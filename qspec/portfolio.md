# 1. 検証概要と結論

## 1.1 検証の目的
QSpecは、高速な W4A4 でドラフトトークンを生成し、高精度な W4A16 で検証する Speculative Decoding 手法である。この仕組みは、両モードのトークン予測が大部分の位置で一致するという観察に基づいている。

本検証では、この性質が実際の QSpec decoding においても確認できるかを調べた。具体的には、各 draft 位置における W4A4 と W4A16 の Top-1 トークンおよび予測確率を記録し、次の点を評価した。

- W4A4 と W4A16 の Top-1 一致率
- 両モードの Top-1 予測確率
- 予測確率と Top-1 一致率の関係

## 1.2 検証条件
評価には GSM8K の test split 全1,319問を使用した。モデルには QuaRot ベースの Llama3_8B_Instruct_QSpec を用い、8-shot プロンプトで QSpec を実行した。  
（論文の Figure 2 は、W4A16 が生成した固定トークン列を Atom ベースの W4A4 と比較している。本検証では、QSpec decoding 中に W4A4 が提案した draft トークンを W4A16 で検証した。このため、本検証は Figure 2 の厳密な再現ではない。）

## 1.3 結果
QSpec の draft-verify 処理で評価された 275,049 個の draft 位置のうち、W4A4 と W4A16 の Top-1 トークンは 263,984 個の位置で一致した。一致率は 95.98%、不一致率は 4.02% であった。

| 指標 | 結果 |
| :-: | :--- |
| リクエスト数 | 1,319 |
| draft位置数 | 275,049 |
| Top-1一致数 | 2633,984 (95.98%) |
| Top-1不一致率 | 11,065 (4.02%) |
| W4A4 の Top-1 確率の平均 | 92.51% |
| W4A16 の Top-1 確率の平均 | 92.99% |

両モードの Top-1 確率が共に 0.8 を超えた位置は、全体の 82.58% を占めた。この領域における Top-1 一致率は 99.96% であった。一方、両方の確率が 0.8 以下の領域では、一致率は 70.56% まで低下した。

## 1.4 結論
今回の条件では、W4A4 と W4A16 の Top-1 トークンは 95.98% の draft 位置で一致した。特に、両モードの Top-1 確率が共に 0.8 を超える場合、一致率は 99.96% となった。  
以上から、W4A4 と W4A16 のトークン予測は大部分の位置で類似し、両モードが高い確信度を示す位置ほど一致しやすいことが確認できた。この結果は、論文で報告されたトークン単位の類似性が、QuaRot ベースの実際の QSpec decoding でも観察されることを示している。

## 2. 背景
### 2.1 W4A4 の速度と精度のトレードオフ
W4A16 は、重みを4ビット、活性化を16ビットで扱う。W4A4 は重みと活性化の両方を4ビットで扱うため、低精度カーネルを利用して高速に推移論できる一方、活性化量子化による精度低下が生じやすい。

QSpec の論文では、WikiText-2 や PIQA における W4A4 の性能低下は比較的小さいものの、GSM8K や MBPP などの多段階推論タスクでは大きく低下すると報告されている。多段階推論では、途中で選択した少数の誤ったトークンが後続の生成に影響し、最終的な回答を変える可能性があるためである。

### 2.2 最終精度が低くても、多くの予測は一致する
W4A4 は多段階推論タスクで性能が低下する一方、トークン単位では W4A16 とよく似た予測を行う。QSpec の論文の Figure 2 では、W4A4 と W4A16 が選択する Top-1 トークンの大部分が一致し、不一致は一部に限られることが示されている。

### 2.3 Top-1 一致率と QSpec の関係
QSpec は、W4A4 を draft 生成に、W4A16 を検証に使用する。W4A4 と W4A16 の Top-1 トークンが多くの位置で一致するなら、W4A4 が高速に生成した候補の多くを利用できる。一方、不一致となる位置では、W4A16 による検証によって差異を検出し、W4A4 の量子化誤差が後続の生成に伝搬することを防ぐことができる。

したがって、Top-1 一致率は次の2点を理解するための重要な指標となる。

- W4A4 が W4A16 に近い候補をどの程度生成できるか
- W4A4 を draft 生成に用いる QSpec の設計が妥当か

ただし、Top-1 一致率は QSpec 実行時の受容率そのものではない。Top-1 一致は両モードが最有力としたトークンの一致を表すのに対し、実際の受容・棄却は使用するサンプリング方式や確率分布にも依存する。本検証では両者を区別し、W4A4 と W4A16 の予測の類似性を Top-1 一致率によって評価する。


## 3. 検証方法
### 3.1 実験方法
評価には、算数文章問題データセット GSM8K の test split 全 1,319 問を使用した。プロンプトは train split から取得した8問を例題として与える 8-shot 形式とし、正解文は評価プロンプトに含めていない。  
推論モデルには、QuaRot ベースの Llama3_8B_Instruct_QSpec を使用した。QSpec では、同じ4ビット量子化済み重みを共有し、活性化の精度を切り替えることで W4A4 と W4A16 を実行する。

| プロンプト | 8-shot |

| draft 長 | 3トークン |

### 3.3 計測方法
QSpec を実行し、各 draft 位置について W4A4 と W4A16 の予測を記録した。1回の draft-verify サイクルでは、W4A4 が最大3個の候補トークンを生成し、W4A16がそれらをまとめて検証する。
各 draft 位置では、主に次の情報を取得した。

- W4A4 が選択した Top-1 トークンとその確率
- W4A16 が選択した Top-1 トークンとその確率
- 両モードの Top-1 トークンが一致したか
- 両モードの Top-1 確率が 0.8 を超えたか

### 3.4 評価指標
検証では、次の指標を集計した。
1. Top-1 一致率: 全 draft 位置のうち、W4A4 と W4A16 の Top-1 トークンが一致した割合。
2. Top-1 予測確率: 各モードが Top-1 トークンに割り当てた確率の平均値と中央値。
3. 高信頼領域の割合と一致率: 両モードの Top-1 確率が共に0.8を超えた位置の割合と、その領域における Top-1 一致率。
4. 低信頼領域の一致率: 両モードの Top-1 確率が共に0.8以下だった領域におけるTop-1一致率。

なお、Top-1 一致と QSpec 実行時の受容は別の指標として扱った。Top-1 一致は両モードの最有力トークンを比較した結果であり、実際の受容・棄却はサンプリング方式や確率分布にも依存する。

## 4.　結果
### 4.1 Top-1 一致率
GSM8K の全1,319問を実行し、QSpec の draft-verify 処理で評価された 275,049 個の draft 位置を分析した。W4A4 と W4A16 の Top-1 トークンは 263,984 位置で一致した。全体の Top-1 一致率は 95.98%、不一致率 4.02% であった。

| 指標 | 結果 |
| :-: | :--- |
| リクエスト数 | 1,319 |
| draft 位置数 | 275,049 |
| Top-1 一致数 | 263,684 (95.98%) |
| Top-1 不一致数 | 11,095 (4.02%) |

この結果から、W4A4 と W4A16 は大部分の draft 位置で同じトークンを最有力候補として選択していることが分かる。

### 4.2 Top-1予測確率
W4A4とW4A16がTop-1トークンに割り当てた確率を集計した。

| 指標 | W4A4 | W4A16 |
| :-: | :--- | :--- |
| 平均 | 92.51% | 92.99% |
| 中央値 | 99.966% | 99.986% |

両モードとも平均値は92%を超え、中央値は99.9%を超えた。このことから、多くの draft 位置では、いずれのモードも特定のトークンに高い確率を割り当てていることが分かる。

### 4.3 予測確率とTop-1一致率の関係
両モードの Top-1 確率がともに0.8を超えた位置は、全体の82.58%を占めた。この領域における Top-1 一致率は99.96%であった。
一方、両モードの Top-1 確率がともに0.8以下の領域では、一致率は70.56%まで低下した。

| 確率の条件 | Top-1一致率 |
| :-: | :--- |
| W4A4とW4A16がともに0.8超 | 99.96% |
| W4A4とW4A16がともに0.8以下 | 70.56% |

両モードが高い確信度を示す位置では、Top-1 トークンもほぼ常に一致した。一方、両モードの確信度が低い位置では、不一致が生じやすい傾向が見られた。

### 4.4 予測確率の分布
1.3 の結果の散布図は、各 draft 位置における W4A16 の Top-1 確率を横軸、W4A4 の Top-1 確率を縦軸に示したものである。

各点は1つの draft 位置を表し、両モードの Top-1 トークンが一致した点を Top-1 Match、一致しなかった点を Top-1 Mismatch として区別している。グラフ上部と右側の密度曲線は、それぞれ W4A16 と W4A4 の Top-1 確率の周辺分布を示す。  
一致した点は右上の高確率領域に集中している。一方、不一致は相対的に確率の低い領域で多く見られた。この分布は、高い Top-1 確率と高い一致率の関係を視覚的にも示している。

## 付録: QSpec の論文

### 論文タイトル
J Zhao et al. "QSPEC: Speculative Decoding with Complementary Quantization Schemes", 2025.

### QSPEC が解決する問題
低精度で高速な W4A4 をドラフト生成に、高精度な W4A16 を検証に利用する Speculative Decoding である。両者で量子化済み Weight と KV キャッシュを共有することで、追加モデルによるメモリ増加を抑えながら、W4A16 相当の生成品質と高速化を両立する。

### 中心的なアイディア
単一の量子化済み重み
Draft フェーズにおいて、Weight-Activation 量子化を適用し、低精度だが高速なドラフト生成を行う。Verify フェーズでは、Weight-only 量子化を適用し、高精度な予測確率を得る。また、W4A4 と W4A16 において重みを別々に保存せず、共有することで効率化する。さらに、KV キャッシュを共有し、検証済みのトークンについて W4A4 による低精度なキャッシュを W4A16 による高精度なキャッシュで上書きする (KV Cache Overwriting)。

## 1.4 主な実験結果
QSpec は W4A16 の生成品質をほぼ完全に維持することができる。従来の W4A4 では、HATH や HumanEval といった多段階推論タスクにおいて大幅な精度低下が見られたが、QSpec ではこれらを補完的に改善することができる。  
また、W4A16 と比較してトークン生成のスループットが最大1.64倍向上する。有効トークンあたりのレイテンシを 26.5-30.6% 削減することに成功している。  
ドラフト生成されたトークンの承認率は、vLLM を用いたテストで 93-95% と非常に高い。KV キャッシュの共有によりメモリオーバーヘッドを低減できている。さらに、スケーラビリティの観点で、バッチサイズが大きくても性能が劣化しにくい(最大32まで検証)。
